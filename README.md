# Nonfiction Studio

Nonfiction Studio is an open-source Claude Code and Cowork plugin that turns Claude into a
governed non-fiction book studio. It provides a structured authoring workflow covering
intake interviews, chapter drafting, claim tracking, fact-checking, voice consistency
scoring, and quality gating - all implemented as composable skills and agents that a
human author drives at their own pace.

**Status: pre-release, under construction against the v2 planning set.**
