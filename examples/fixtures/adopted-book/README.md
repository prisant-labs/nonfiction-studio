# Counting What Matters

A short nonfiction manuscript by Dana Whitlock, a fictional author. It is a test fixture for
adopting an existing book: it was written without Nonfiction Studio, in its own layout.

## Standing rules

- Every empirical claim in the ledger carries a status.
- A preprint is labeled as a preprint at every use.
- Every claim ID carries a readable handle.

## Layout

- `manuscript/` holds the chapters, an introduction and an author's note.
- `research/` holds the interview guide and the research-ethics protocol.
- `evidence/claim-ledger.md` is the claim ledger.
