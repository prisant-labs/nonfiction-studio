# Changelog

All notable changes to Nonfiction Studio are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); this project uses [Semantic Versioning](https://semver.org/) once a version is tagged. See `MIGRATION.md` for what counts as a breaking change to a book already in progress, and `RELEASE-NOTES.md` for curated, user-facing summaries of each release.

This file is written from the commit history of the branch it ships from, not from a plan or a roadmap: an entry here means the change actually landed, not that it was intended.

## Unreleased

### Added

- Agent identity resolution from the hook envelope, activating two previously dormant guards: the research-agent write-scope containment, F-AG-01 (dormant write-path containment), and the web research gate that blocks unapproved online lookups, F-AG-02 (web gate unenforced). `ai-use-log` entries now attribute chapter writes to the real acting agent instead of a placeholder, D-10 (compliance layer is a feature). Recorded in ADR-0007 (agent identity resolution).
- A verbatim quote ledger field and a quote-fidelity engine, D-07 (claim ledger), plus a `quote_fidelity` quality-gate check registered warn-only by construction, D-03 (layered Stop gate).
- The untrusted-fetch envelope hook, OPP-P04 (untrusted-source envelope): wraps every WebFetch and WebSearch result in an untrusted-content envelope (a preamble stating the content is data, not instructions, plus a per-fetch nonce fence a hostile payload cannot forge) before Claude sees it, and appends one append-only record per fetch to `.studio/logs/fetches.jsonl`, D-06 (single-writer state discipline).
- `ns-notes`, the seventh shipped CLI, OPP-D05 (apparatus generator): generates Chicago-style endnotes, a deduplicated bibliography, index-term candidates, and a needs-attention list from the evidence ledger. Read-then-emit only - it never writes to `research/evidence-log.md`, `research/sources.md`, or `chapters/*.md`, only to `production/{endnotes,bibliography,index-candidates,apparatus-attention}.md`. Ships with `hooks/lib/citation-styles/chicago.json` (the Chicago style expressed as data) and the `build-apparatus` skill. Recorded in ADR-0009 (apparatus CLI and D-05 (five CLIs) growth).
- `quick-scan` and `tour`, two onboarding skills closing OPP-D17 (five-minute first win): `quick-scan` measures 500 to 1000 pasted words with the existing `ns-stylometry --measure` mode and reads the same prose for sentences needing a source, writing only to a temp file, never the repo. `tour` runs a disposable copy of the sample book through a real gate pass, a planted AI-residue violation, a real block, and a recovery, without ever modifying `examples/`. `docs/quickstart.md` documents the fast path, and `README.md`'s Quickstart now leads with it.
- `scripts/checks/check-workspace-refs.mjs`, a Tier A check closing C2 (enforcement theater): derives the forbidden-directory set from `.gitignore` and scans the shipped tree for three plain-text forms of a reference to scratch workspace content that vanishes on a clean checkout.
- `ns-statusline`, the sixth shipped CLI, and its engine: a zero-token deterministic status view of active chapter, word progress against target, open claims, drift band, and gate state, per OPP-P03 (studio HUD). Ships via a `subagentStatusLine` declaration plus an explicitly consented, one-time install step in the `doctor` skill; `ns-doctor` itself stays read-only without exception. Recorded in ADR-0008 (status HUD and CANON 3.5).
- Tier B model-integration CI, triggered by manual `workflow_dispatch` only, on `CLAUDE_CODE_OAUTH_TOKEN` subscription authentication rather than an API key; a shared, honest three-state credential decision (`scripts/lib/credential-mode.mjs`) used by both `scripts/run-integration.mjs` and `scripts/run-evals.mjs`, replacing a probe that could only prove the `claude` binary existed, never that anyone was authenticated - F-CI-02 (Tier B trigger contradicts D-20). A dispatch-accuracy failure threshold (`scripts/lib/dispatch-threshold.mjs`) so a genuinely broken dispatch table now turns a live Tier B run red. Recorded in ADR-0010 (Tier B trigger and credential).
- A tag-triggered release workflow (`.github/workflows/release.yml`) that verifies a pushed version tag agrees with `library.json`, `package.json`, and `.claude-plugin/plugin.json` before publishing a GitHub release from `RELEASE-NOTES.md`.
- `CHANGELOG.md`, `RELEASE-NOTES.md`, and `MIGRATION.md`, closing F-ST-11 (no release automation), F-DX-13 (no shipped versioning policy), and F-DX-14 (no changelog).
- `ns-status`, the eighth shipped CLI (D-05, five shipped CLIs, now eight): a deterministic, read-only project chapter board and whole-book totals computed from `.studio/progress.json`, `.studio/config.json`, and the newest gate report per chapter slug under `.studio/gate/`. The `status-dashboard` skill now narrates this CLI's JSON output in a single Bash call instead of listing `.studio/gate/`, parsing filenames, or extracting a drift number out of report prose itself.
- The chapter promotion ceremony and automatic demotion: reaching the terminal `final` status now requires a dated human attestation entry in `context/decisions.md` (actor `author`, all required fields present, `links` naming the chapter slug). `hooks/post-tool-batch.mjs` automatically falls a chapter back to `revised` when it is edited after reaching `final`, or found `final` with no matching attestation even with no chapter write in the current batch, so the board cannot claim a chapter is finished after it changed. The eligibility predicate has one shared implementation between the hook and the board.
- A frozen, labeled drift-calibration scenario suite (`tests/engines/fixtures/drift-scenarios/`), used to recalibrate the stylometry drift budget against measured, ground-truthed scenarios rather than by inspection.
- `scripts/checks/check-skill-cli-targets.mjs`, a Tier A checker that scans `skills/**/SKILL.md` for `bin/ns-<name>` routing-target references and asserts each named CLI is actually shipped under `bin/`, closing F-CI-07 (dispatcher and CLI-wrapper skills uncovered).
- `scripts/checks/check-component-counts.mjs`, a Tier A checker that derives the true CLI and skill counts from the tree at run time and fails on a stale prose claim about either total, naming the file, line, claimed value, and true value, and reporting every violation rather than stopping at the first - the same remedy `check-workspace-refs.mjs` already proved, applied to the stale-component-count defect that recurred across four separate fixes in the previous wave.
- `ns-stylometry --explain`, closing half of roadmap row 1.7 (voice registers): renders the per-marker data `computeDrift` already computed but never returned or printed - each marker's baseline value, measured value, honest (uncapped) deviation, actual contribution to the score, whether the per-marker contribution bound was binding for it, and whether it crossed the per-marker tolerance band, ordered by contribution descending so the marker that drove the verdict reads first. Composes with both the human-readable and `--json` output modes rather than replacing either, leaves the exit-code taxonomy unchanged, and writes nothing to disk; a `--json` consumer who never passes the flag sees the same output shape as before it existed.

### Changed

- Six skill verb triggers rephrased from "legacy" framing (implying a deprecated slash command) to "alias" framing (this plugin has no `commands/` directory at all, so no verb was ever a registered command to deprecate) - F4 (verb vocabulary).
- The Stop hook's check list now derives from the quality gate engine's own registry instead of a separately hand-maintained copy, and a third duplicated `foldForCompare` implementation was collapsed into the shared module.
- Self-sufficiency scanning closed blind spots in its scanned-file set (`examples/` was previously unscanned for provider-key patterns) and gained negative tests proving each checker can genuinely fail on a planted violation, not only pass - F6 (checker negative tests), F7 (scan-set blind spots).
- A second detector, `scanPromptInjection`, was built to flag instruction-override phrasing directed at an assistant in fetched web content, then adversarially tested and removed across four review rounds: every narrowing tried, down to its tightest form, false-positived on realistic content in the exact domains the untrusted-fetch hook scans (support FAQs, changelogs, security blogs, and ordinary developer documentation), because pattern matching could not separate an imperative addressed to an assistant from the same words used to describe, report, or instruct a human reader. This hook does not attempt instruction-override detection, by deliberate decision, not oversight; the unconditional wrap and fence remain the actual defense regardless of scanner findings, per AR-07 (security, privacy and safety) and D-13 (security posture).
- Stylometry drift scoring corrected: `type_token_ratio` is now a length-invariant moving average over 100-token windows instead of a flat ratio that fell monotonically as text grew, and no single marker's contribution to the drift score may exceed one third of the configured budget (`MARKER_CONTRIBUTION_DIVISOR`), so a single near-zero-baseline marker can no longer decide a verdict alone.
- The default drift budget (`DEFAULT_DRIFT_SCORE_MAX`) recalibrated from 35 to 25 against the new labeled scenario suite, closing a gap where a chapter stripped of every contraction and every first-person pronoun (the canonical ghostwriting signature) passed at the old default. Every scaffolded book carries an explicit `thresholds.drift_score_max`, so only a book that omits the key from `.studio/config.json` sees the new default.
- A stylometry baseline now carries a `stylometry.baseline.marker_set_version` field; `computeDrift` refuses to score a baseline captured under a different marker set version, raising a named `StaleBaselineError` that names `capture-voice` as the remedy. `bin/ns-stylometry --measure` emits the version alongside the marker vector so the capture path carries it by construction.

### Fixed

- The stylometry engine now folds typographic quotation characters to their ASCII equivalents before measuring, and `marker_set_version` moves from 2 to 3 to record the change in meaning. `CONTRACTION_RE` matched only U+0027, so `contraction_rate` read exactly 0 for prose written with the U+2019 apostrophe that Word, Google Docs, and Obsidian emit by default; an author who pasted writing samples from any of them captured a zeroed contraction marker, and every chapter they later wrote with a plain apostrophe read as a 100 percent deviation on it. `PUNCT_RE` had the same ASCII-only assumption and omitted every smart double quote. U+2026 (ellipsis) is deliberately NOT folded, because expanding it to three periods would count as three punctuation characters and could introduce a spurious sentence boundary; a test pins that decision. No baseline value stored in this repository moves, because no tracked file uses those characters; the version bump is for baselines captured outside it. Found while preparing corpus material for the drift-calibration work, not by a report.
- The dormant write-scope guard and web research gate were activated for real; the agent prose that had claimed this enforcement existed is now literally true rather than aspirational - F-AG-01 (dormant write-path containment), F-AG-02 (web gate unenforced).
- A corrupt `.studio/config.json` no longer silently suppresses the shell destructive-command caution for non-write tools - F8 (corrupt config suppresses the shell caution).
- Sample-book gate fixtures and chapter voice now reflect genuine `ns-gate`/`ns-doctor` output instead of hand-authored approximations, including synced word-count and fixture-name assertions - F5 (gate fixture shape).
- Claims-ledger entries now use durable IDs, a dead field was dropped, and mutually exclusive CLI flags are now enforced rather than silently accepted together.
- A self-sufficiency test that was tripping on scanning its own source file is fixed.
- Removed stale scratch-workspace path references left behind in an earlier task's tests.
- Sample-book and fixture baselines recaptured under the corrected stylometry engine and stamped `marker_set_version: 2`.
- A gate run against a baseline missing `marker_set_version` (every baseline captured before this release) now surfaces plainly instead of going silent: the status-dashboard skill's next-actions list names the affected chapter and the `capture-voice` remedy instead of reaching a false all-clear, the Stop hook's error detail names the same remedy instead of a generic exit-code line, and `run-quality-gate`'s pre-check warns before the gate runs instead of only after.
- Stale threshold and CLI-count claims scattered across docs and code comments (a leftover default of 35 quoted in several example gate reports and comments after the budget moved to 25; CLI counts left at five, six, or seven after later CLIs shipped) corrected against the current tree.
