# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. If anything below and the Covenant text ever seem to
disagree, the Covenant text governs.

## In short

Be respectful and assume good faith. Harassment, personal attacks,
discriminatory language or conduct, and other unprofessional behavior are
not welcome here, in issues, pull requests, discussions, commits, or any
other space where this project is represented.

## Scope

This applies within all project spaces - issues, pull requests, code
review, discussions, and commit messages - and also applies when someone is
representing the project in public spaces, such as posting via an official
project social media account or acting as an appointed representative at
an event.

## Reporting

This project is solo-maintained; there is no public contact email, and
there is one private channel for both security and conduct reports. To
report a conduct concern, use this repository's **Security** tab and choose
**Report a vulnerability** - it is labeled for security reports, but it is
the one private, repository-level channel this project has enabled, it
reaches the maintainer directly, and it works fine for a conduct report
too. If that form is unavailable to you, contact
[@jprisant](https://github.com/jprisant) on GitHub instead.

Reports are handled on a best-effort basis by a single maintainer; there is
no SLA. You will get an acknowledgment, and reports are kept private to the
extent doing so is possible while addressing them.

## Enforcement

Enforcement follows the Contributor Covenant's own
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
adopted by reference rather than reproduced here: a graduated ladder from a
private correction, through a warning and a temporary interaction ban, up
to a permanent ban for severe or repeated violations. The maintainer
decides which level applies, using their best judgment given the
circumstances.
